# Well Rounded Engineer: labs

Short drills for the free guide [Well Rounded Engineer — More Human](https://enrichmeai.com/well-rounded-engineer/):
small pieces of broken code with tests, to fix in 10 to 20 minutes a day, in Python or Java.

Drills are added one pull request at a time.
